Takeaways

  • Most ReDoS is quadratic, not exponential. 15 of 20 catalogued patterns (75%) blow up at O(n²) — bad enough to hang a request thread, but slower to reveal itself in testing than the textbook exponential (a+)+ case.
  • Most fixes just remove ambiguity in the regex. 15 of 20 (75%) were fixed by rewriting the pattern so a crafted input can only be matched one way — no algorithm change, no input cap.
  • Some real fixes don't touch the regex at all. A few well-known packages shipped an input-length cap or replaced the regex with plain string parsing — a useful reminder that "rewrite the regex" isn't the only mitigation.
  • It spans ecosystems. 14 npm and 3 PyPI CVEs here, each verified on the engine it actually ships on (V8 RegExp / CPython re).
